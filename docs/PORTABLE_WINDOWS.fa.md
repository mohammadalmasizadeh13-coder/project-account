# نسخهٔ قابل‌حمل ویندوز

خروجی `Zarnegar-Portable` شامل `Zarnegar.exe`، محیط اجرای Python و کتابخانه‌ها در `_internal`، فایل‌های ساخته‌شدهٔ رابط و پوشهٔ `data` است. کاربر مقصد کل پوشه را منتقل می‌کند و EXE را باز می‌کند؛ نصب Python یا Node.js روی مقصد لازم نیست. خروجی برای ویندوز ۱۰/۱۱، ۶۴ بیتی ساخته می‌شود.

برنامه سرور را فقط روی `127.0.0.1` اجرا می‌کند و مرورگر پیش‌فرض را پس از آماده‌شدن سرور باز می‌کند. بستن پنجرهٔ کوچک اجرای برنامه سرور را نیز متوقف می‌کند. مسیر داده‌ها از محل EXE تعیین می‌شود، بنابراین تغییر درایو، نام پوشه و مسیر شامل فاصله یا حروف فارسی مجاز است. پوشه باید برای کاربر قابل‌نوشتن باشد.

## ساخت روی ویندوز

این مراحل فقط روی رایانهٔ سازنده به Python و Node.js نیاز دارند. ابتدا محیط `backend/.venv` و وابستگی‌های `backend/requirements.txt` را طبق راهنمای اصلی آماده کنید. سپس از ریشهٔ پروژه:

```powershell
# نسخهٔ خالی
.\build-portable.ps1

# نسخه همراه یک کپی از حساب‌ها و فایل‌های فعلی
.\build-portable.ps1 -IncludeCurrentData -OutputDirectory Zarnegar-Portable-WithData
```

اسکریپت ابزارهای ساخت را از `portable/requirements-build.txt` نصب می‌کند، رابط را می‌سازد و با [PyInstaller](https://pyinstaller.org/en/stable/operating-mode.html) خروجی پوشه‌ای تولید می‌کند. نام پیش‌فرض پوشه `Zarnegar-Portable` است و یک ZIP کنار آن ساخته می‌شود. اگر خروجی قبلاً موجود باشد، ساخت متوقف می‌شود تا اطلاعات کاربر بازنویسی نشود؛ نام خروجی تازه انتخاب کنید.

حالت انتقال اطلاعات، مسیر SQLite و uploads را از `backend/.env` می‌خواند؛ در نبود تنظیم، از `backend/zarnegaar.db` و `backend/uploads` استفاده می‌کند. SQLite با API پشتیبان‌گیری کپی می‌شود تا تراکنش‌های ثبت‌شدهٔ WAL نیز منتقل شوند. حساب‌ها و رمزهای موجود حفظ می‌شوند؛ نشست‌های ورود در کپی پاک می‌شوند و روی مقصد باید دوباره وارد شد. فایل `.env` و تنظیمات خصوصی میزبان همراه برنامه کپی نمی‌شوند. برای یکسان بودن فایل‌های بارگذاری‌شده و دفتر، هنگام ساخت نسخهٔ انتقال، ثبت و حذف اطلاعات جدید انجام ندهید.

پوشه و ZIP خروجی ممکن است شامل اطلاعات خصوصی حسابداری باشند و در Git نادیده گرفته می‌شوند. فقط کد ساخت و راهنما در GitHub ذخیره می‌شود.

## بررسی

```powershell
backend\.venv\Scripts\python.exe -m pytest portable/test_launcher.py portable/test_build.py
backend\.venv\Scripts\python.exe portable/smoke_exe.py Zarnegar-Portable --check-gui
```

آزمون فایل اجرایی، فقط EXE و `_internal` را به یک پوشهٔ آزمایشی جدا کپی می‌کند و با داده‌های ساختگی، اجرا، ثبت‌نام، ذخیره، توقف و انتقال مسیر را بررسی می‌کند. اطلاعات واقعی توزیع خوانده یا تغییر داده نمی‌شود.

## انتقال و نگهداری

ZIP را کاملاً استخراج کنید و EXE را داخل پوشهٔ استخراج‌شده اجرا کنید. برای جابه‌جایی و پشتیبان‌گیری، برنامه را ببندید و کل پوشه را کپی کنید. پوشهٔ `data` شامل دفتر و حساب‌هاست؛ در به‌روزرسانی حفظ شود. نسخه‌های دو لپ‌تاپ مستقل‌اند و همگام‌سازی خودکار ندارند. راهنمای مصرف‌کننده در `READ-ME.fa.txt` همراه خروجی است.
